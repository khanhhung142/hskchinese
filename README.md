# hskchinese

Personal Chinese vocab trainer: a static PWA (vanilla JS, no build) served by GitHub Pages.

- `data/vocab.json` holds lessons, words and example sentences. Hermes (on the Raspberry Pi) fills it from lesson photos, following [hermes/hsk-vocab/SKILL.md](hermes/hsk-vocab/SKILL.md).
- `audio/` holds one Edge TTS mp3 per word and sentence, generated by `tools/check.mjs`.
- The app builds exercises from the data at runtime (`js/quiz.js`).

```sh
npm test                 # unit tests
npm run check            # format + validate data, sync audio (needs edge-tts on PATH or EDGE_TTS=...)
python3 -m http.server   # run locally at http://localhost:8000
```
